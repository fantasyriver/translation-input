# 验证记录与人工验收清单

日期：2026-10-01。环境：macOS 15.1.1、Apple Silicon、Command Line Tools Swift 6.0.3；开发版 ad-hoc 签名。当前架构为客户端直接调用模型 API。除注明通过外，以下项目仍待验收。

## 已执行

- Swift 10 组核心行为检查：会话取消、单次消费、旧响应淘汰；URL 安全策略；六家及自定义请求构造；两类响应解析、空/超大/截断/拒绝响应、思考分离；凭据作用域与独立配置；快捷键独立保存、失败保持旧值和系统冲突。每组包含多条断言。
- 本地真实 URLSession 集成 22 个场景：六家请求与 Unicode；401/403/404/429/500/504/307；截断、空、无效 JSON、声明/未声明长度的超大响应、拒绝；空 Key 本机服务；响应头前和响应体中的取消。测试确认没有跟随重定向、没有应用级自动重试。
- 独立代码审查后补回归：兼容 `tool_calls: []` / `null` / 缺省；非空工具调用与错误类型继续拒绝。新增断言先失败，修正后通过。
- 原生设置页已打开并检查布局：六家及自定义菜单存在，切换 Claude 自动填 Messages 地址/模型/协议；再切 MiniMax 正确恢复 OpenAI 协议及中国区地址。缺少 Key 保存时显示明确提示。
- 已有自定义快捷键在新设置页保持，快捷键无需模型配置即可使用原有设置流程。
- Release `.app` 构建与 `codesign --verify --strict` 通过，当前机器架构为 arm64；MIT 许可证随应用资源打包。
- 2026-09-26 已检查悬浮输入框、12 种目标语言、Unicode 多行显示、编辑菜单和 Esc；本轮没有修改输入控件及回填实现。
