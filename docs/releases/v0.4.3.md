# 译入 v0.4.3 · 首个公开测试版

原生 macOS 翻译输入工具：按快捷键唤起，输入任意语言，翻译后复制或回填到原输入位置。

## 下载与安装

- 支持 Apple Silicon（M 系列芯片），macOS 14 或以上。
- 下载下方 Assets 中的 **TranslationInput-v0.4.3-macos-arm64.zip**，解压后将 `TranslationInput.app` 拖入“应用程序”。
- 测试版采用临时开发签名，尚未经过 Apple 公证。首次打开可能需要在“系统设置 → 隐私与安全性”中确认“仍要打开”。
- 完整步骤：[安装、授权与升级指南](https://github.com/fantasyriver/translation-input/blob/v0.4.3/docs/installation.md)。
- `SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。

## 功能

- 全局快捷键唤起，默认 Option + Space，可自定义。
- 原生输入框，支持系统输入法与 12 种目标语言。
- 本地配置模型服务与 API Key，直接调用 OpenAI、Claude、DeepSeek、GLM、MiniMax、通义千问及自定义兼容接口。
- 译文自动复制；可回填时发送到原输入位置并隐藏窗口。
- 快捷键重新唤起时清空旧输入，进入新一轮翻译；设置返回保留草稿。
- 双向箭头与插入光标组成的菜单栏图标，支持系统深浅色。

## 测试版说明

- 自动回填需要用户开启辅助功能权限；更新开发版后可能需要移除旧条目再添加当前应用。
- 对目标应用和控件的支持仍在验证中；回填失败时译文保留在窗口和剪贴板，可手动粘贴。
- 本次安装包为 arm64；Intel Mac 用户可参考仓库构建说明自行构建，Intel 环境尚未验收。
- API 调用使用用户自己的账户，费用由模型提供商计费。
- 后续更新通过 Releases 下载并手动替换应用。
