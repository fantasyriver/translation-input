# 回填后隐藏输入窗口

用户已确认重新授权后，快捷键唤起、翻译和回填成功。此次调整成功后的窗口行为：回填操作发出后隐藏面板，继续在原应用输入。

- 在 `DeliveryOutcome.insertion == .sent` 分支调用 `panel.orderOut(nil)`，时机在会话有效性校验和忙碌状态清理之后。
- 未开启回填、目标不可用、回填失败或翻译失败时保持窗口可见，便于查看译文或重试。
- 保留剪贴板、原文、内联译文和已有焦点校验。重新唤起仍可查看结果。
- 使用现有交付流程回归验证成功、跳过、失败和过期会话；构建 Release 并检查签名。真机自动隐藏需要在新开发包重新授权后验收。

系统粘贴事件没有通用的完成回执，此处“成功”指通过目标检查并已向目标进程发送粘贴事件。
