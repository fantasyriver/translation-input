# 译入界面精修

目标：以视觉设计、操作清晰度、交互完整性和执行品质为标准，完善原生 macOS 输入工具。

## 设计方向

- 暖白底色、墨色文字、翡翠绿主操作；深色模式采用相同的语义层级。
- 输入窗口：清晰的品牌标记、原文卡片、独立语言与翻译操作区、紧凑状态栏。
- 设置窗口：模型服务与使用偏好分组，统一字段高度、标签、留白和操作反馈。
- 原生 AppKit 控件、SF Symbols、系统字体；保留输入法、快捷键、钥匙串和回填机制。

## 验收与迭代

1. 保存现状截图并审查层级、密度、对齐、可读性。
2. 实现共享配色、卡片、按钮与状态组件；调整两个窗口。
3. 在真实窗口检查空输入、长文本、提供商切换、验证错误、快捷键录制与取消。
4. 根据截图修正比例、布局与反馈；执行核心、HTTP 和构建检查。
5. 独立代码审查，记录实际验证范围，发布源码与开发包。

本轮不更改模型协议、凭据作用域或自动回填的安全判定。
